## Repository Structure Overview

* **`submission_docs/`**: Coursework worksheets, academic reports, and assignment deliverables (this folder).
* **`RBER_Research_Paper.md`**: Formal theoretical research paper detailing the Recursive Boundary Exposure Retrieval (RBER) algorithm.
* **`backend/`**: Production FastAPI retrieval server with SQLite persistence, binary embeddings, and optimized End-to-Middle boundary search.
* **`frontend/`**: React 18 / Vite workspace UI for uploading, inspecting, and querying documents.
* **`benchmark/` & `benchmarks/`**: Empirical LongBench evaluations and needle-in-a-haystack synthetic retrieval audits.
* **`tests/`**: Automated test suite for retrieval mechanics, reconstruction, and API integrity.
